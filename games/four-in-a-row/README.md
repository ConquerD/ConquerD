# Four in a Row

Drop discs into seven columns, alternating mint (1) and lilac (2). Connect four
horizontally, vertically or diagonally. Anyone can play either side; this is an
open tabletop, also usable for local pass-and-play. A full board draws. New round
clears the board for everyone. Concurrent moves resolve to one shared position.

Open `d://<supernode_id>/games/four-in-a-row/?room=lounge` in DoubleSlash.
Share the same app/room on the same supernode or cluster. State survives while
at least one page remains open. See [the portal guide](../README.md) for transport,
synchronization limits, bundling and verification.
