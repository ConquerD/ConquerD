# Memory Match

Reveal two cards and find all eight pairs together. A matching pair stays face
up. A mismatch waits for Hide missed pair so everyone has time to see it. Shuffle
and restart deals a new board for everyone. Cards are held in page memory; this
is a cooperative demo, not a competitive anti-cheat game.

Open `d://<supernode_id>/games/memory-match/?room=lounge` in DoubleSlash.
Share the same app/room on the same supernode or cluster. State survives while
at least one page remains open. See [the portal guide](../README.md) for transport,
synchronization limits, bundling and verification.
