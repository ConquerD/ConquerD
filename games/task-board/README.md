# Task Board

An eight-row shared checklist. Edit a row and press Enter or leave the field to
share it; check off tasks or clear a row from any device. Each row is limited to
80 characters and syncs independently. Concurrent edits to the same row resolve
to one value. The board lives only in open pages.

Open `d://<supernode_id>/games/task-board/?room=lounge` in DoubleSlash.
Share the same app/room on the same supernode or cluster. State survives while
at least one page remains open. See [the portal guide](../README.md) for transport,
synchronization limits, bundling and verification.
