# Focus Timer

Choose 25 minutes of focus, a 5-minute break or a 15-minute session. Start, pause
and reset together. The shared deadline keeps countdown traffic small; device
clocks need to agree. There are no alarms or background notifications.

Open `d://<supernode_id>/games/focus-timer/?room=lounge` in DoubleSlash.
Share the same app/room on the same supernode or cluster. State survives while
at least one page remains open. See [the portal guide](../README.md) for transport,
synchronization limits, bundling and verification.
